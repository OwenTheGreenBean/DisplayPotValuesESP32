#Overview#
Once wired up the ESP32 microcontroller will be able to read the analog values coming from the potentiometer and display this value on a 0.96 OLED screen using I2C communications. This 
code and set up is the same I used in this video https://youtube.com/shorts/k95kB0t39CE

##Wiring##

Pin34 Potentiometer analog in
Pin22 SCL
Pin21 SDA
Gnd Gnd
VCC is onboard 3.3v
